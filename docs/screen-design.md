# 画面デザイン

[要件定義書](requirements.md) の「画面」の詳細。実際に作った画面（`src/App.jsx`）に合わせている。
画面は 1 つだけ。

## 完成デザイン（文字と線の図）

```
┌────────────────────────────────────┐
│        製造数量カウンター               │
│                                    │
│  商品名                              │
│  ┌──────────────────────────────┐  │
│  │ 例: 架空クッキー                 │  │
│  └──────────────────────────────┘  │
│                                    │
│  [−1] [数量を直す 123] [決定] [リセット] │  ← 小さい操作（上のほう）
│                                    │
│  ┌──────────────────────────────┐  │
│  │         現在の数量              │  │
│  │                              │  │
│  │            123               │  │  ← 特大の数字
│  └──────────────────────────────┘  │
│                                    │
│  ┌──────────────────────────────┐  │
│  │              ＋1              │  │  ← 大きなボタン（青）
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

## 部品と役割
| 部品 | 要件 | 見た目・動き |
|---|---|---|
| 商品名の入力欄 | F7 | 50 文字まで。入力すると自動で保存される |
| −1 ボタン | F3 | 小さい。数量が 0 のときは押せない（薄く表示） |
| 数量を直す欄 | F4 | 数字だけ入力できる（9 桁まで）。マイナス・小数・文字は入力できない |
| 決定ボタン | F4 | 普段は薄く、押せない。入力中だけ緑になって押せる。Enter でも確定できる。空のまま決定すると 0 |
| リセットボタン | F6 | 小さい。赤い文字。押すと確認メッセージが出る |
| 現在の数量 | F2 | 画面中央に特大の数字。画面の幅に合わせて大きさが変わる |
| ＋1 ボタン | F1 | 青の大きなボタン（高さ約 112px）。親指で押しやすい位置 |

## 配置の考え方
- 押し間違いしやすい −1・数量を直す・リセットは、親指の付け根が当たりにくい画面の上のほうに置く。
- ＋1 は大きくして、親指で押しやすい位置に置く。
- 画面の幅は最大 640px。それより広い画面では、中央に寄せる。
