# 技術スタック（使っているツールとバージョン）

[要件定義書](requirements.md) の「技術スタック」の詳細。
**使うツールを足したり、バージョンを上げたりしたら、この表も更新する。**
確認日: 2026-11-13

## 実行環境
| 項目 | バージョン | 役割 |
|---|---|---|
| Windows | 10 Home（10.0.19045） | 開発に使っている OS |
| Node.js | 24.22.1 | JavaScript を動かす道具（開発用） |
| npm | 11.19.1 | 部品（パッケージ）の管理 |
| JavaScript | （番号なし） | 画面のプログラムを書く言語。Node.js とブラウザで動く |

## アプリで使う部品
| 名前 | バージョン | 役割 |
|---|---|---|
| React | 19.3.1 | 画面を作る部品 |
| React DOM | 19.3.1 | React の画面をブラウザに表示する |
| Vite | 8.3.8 | 開発用サーバーと、公開用へのまとめ（ビルド） |
| @vitejs/plugin-react | 6.3.0 | Vite で React を使うための追加部品 |
| oxlint | 1.93.0 | コードの書き方をチェックする（lint） |

## 開発の道具
| 名前 | バージョン | 役割 |
|---|---|---|
| Git | 2.55.0 | 変更の記録 |
| GitHub CLI（gh） | 2.100.0 | Issue・PR の作成 |

## 保存
- ブラウザの localStorage（サーバー・DB なし）。詳しくは [データ設計](data-design.md)。

## 起動
- `npm run dev`（ポート 5173 で固定）

## メモ
- 部品のバージョンの正確な値は `package-lock.json` に固定されている。
- 動作確認したブラウザのバージョンは、まだ記録していない。確認したら追記する。
