# 技術スタック（使っているツールとバージョン）

[要件定義書](requirements.md) の「技術スタック」の詳細。
**使うツールを足したり、バージョンを上げたりしたら、この表も更新する。**
確認日: 2026-11-14（`npm outdated` で最新、`npm audit` で脆弱性 0 件を確認）
方針: 正式公開された安定版の最新を使う（β版などは使わない）。OS（Windows など）のバージョンは載せない。

## 保存
- ブラウザの localStorage（サーバー・DB なし）。詳しくは [データ設計](data-design.md)。

## 起動
- `npm run dev`（ポート 5173 で固定）

## メモ
- いまは安定版の最新で問題なく動いているので、わざと古い版にしているものはない。そうしたほうがよい場面（他のツールとの相性など）が出たら、理由を添えてここに書く。
- 部品のバージョンの正確な値は `package-lock.json` に固定されている。
- 動作確認したブラウザのバージョンは、まだ記録していない。確認したら追記する。
