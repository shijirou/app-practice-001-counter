# ペルソナ（架空）

> **案**。ユーザー確認後に確定する。

## 基本
- 名前・年代・仕事: 製造架空ハナコ（架空）・40 代・製造スタッフ
- 使う機器: 作業場のタブレット、事務所のパソコン
- IT の得意さ: 苦手。Excel は転記で使う程度

## 一日の流れ・アプリを使う場面
- 製造ラインで商品を作るたびに、数量を記録する。
- 作業中は手が汚れたりぬれたりすることがあり、細かい操作がしにくい。
- 休憩や中断で画面を離れ、戻ってから続きを記録する。
- 作業終了後、合計数量を確認して Excel に転記する。

## 困っていること
1. 正の字の書き忘れや数え間違いが起きる。
2. 終了後の Excel 転記に時間がかかる。

## 望んでいること（このアプリでどうなれば嬉しいか）
1. ボタンを押すだけで数えられ、間違いが減る。
2. 中断しても数量が消えず、合計をすぐ確認できる。
