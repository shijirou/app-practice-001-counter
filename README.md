# 製造数量カウンター

架空の食品会社（株式会社架空食品）向けの、製造数量を数えるカウンターアプリ。パソコン・タブレットのブラウザで、加算・合計表示・修正ができ、画面を閉じても数量が残る。AI を使ったアプリ開発の練習用。

## クライアントとペルソナ（要約・架空）
- **クライアント**: 株式会社架空食品（架空）。食品の製造・加工を行う会社。
- **困りごと**: 製造数量を紙に正の字で記録しており、記録漏れや数え間違いが起きる。終了後の Excel 転記にも手間がかかる。
- **ペルソナ**: 製造架空ハナコ（架空・案）。40 代の製造スタッフで、IT は苦手。
- **作るもの・作らないもの**: パソコン・タブレットで使える製造数量カウンター（加算・合計表示・修正・中断後も保持）。Excel 出力は今回は対象外の想定。
- 詳しくは [クライアント情報](docs/client-brief.md)・[ペルソナ](docs/persona.md)。長いので、必要なときだけ読む。

## 起動方法
### 必要なもの
- Node.js（24 で確認）と npm

### はじめて動かすとき
```
npm install
```

### 起動する
```
npm run dev
```
ブラウザで http://localhost:5173 を開く（ポートは 5173 で固定）。

### 止める
起動したターミナルで `Ctrl + C`。

### そのほかのコマンド
- `npm run build`: 公開用にまとめる
- `npm run lint`: コードの書き方をチェックする
- `npm test`: 自動テストを動かす（22 件）

## 使い方
1 画面で、次の操作ができる。
- **＋1**: 大きなボタンを押すと、数量が 1 増える。
- **現在の数量**: 画面の中央に大きく表示される。
- **商品名**: 入力すると、画面に残る。
- **－1**: 押し間違いのとき、1 減らす（0 より下にはならない）。
- **数量を直す**: 数字を入力して「決定」を押すと、その数量になる（空のまま決定すると 0）。入力中だけ「決定」が緑になる。
- **リセット**: 確認のあと、数量を 0 に戻す。

数量と商品名は、使っている端末のブラウザに自動で保存される。画面を閉じても、続きから使える。
押し間違いを防ぐため、小さい操作（－1・数量を直す・リセット）は画面の上のほうに置いている。

### 作るもの
パソコン・タブレットで使う、製造数量のカウンター。

### 機能一覧
1. 加算（+1）
2. 合計表示
3. 減算（-1）
4. 数量の直接修正
5. 中断後も数量を保持（ブラウザ内に保存）
6. リセット（確認つき）
7. 商品名の入力

### 技術スタック
React 19 + Vite 8（JavaScript）、Node.js 24。保存はブラウザの localStorage。バージョンの一覧は [技術スタック](docs/tech-stack.md)。

### 対象外
複数商品、履歴、Excel 出力、複数端末での共有、スマートフォン最適化。
