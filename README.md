## クライアントとペルソナ（要約・架空）
- **クライアント**: 株式会社架空食品（架空）。食品の製造・加工を行う会社。
- **困りごと**: 製造数量を紙に正の字で記録しており、記録漏れや数え間違いが起きる。終了後の Excel 転記にも手間がかかる。
- **ペルソナ**: 製造架空ハナコ（架空・案）。40 代の製造スタッフで、IT は苦手。
- **作るもの・作らないもの**: パソコン・タブレットで使える製造数量カウンター（加算・合計表示・修正・中断後も保持）。Excel 出力は今回は対象外の想定。
- 詳しくは [クライアント情報](docs/client-brief.md)・[ペルソナ](docs/persona.md)。長いので、必要なときだけ読む。

## 要件定義
詳しくは [要件定義書](docs/requirements.md)。

### 作るもの
パソコン・タブレットで使う、製造数量のカウンター。

### 機能一覧
1. 加算（+1）
2. 合計表示
3. 減算（-1）
4. 数量の直接修正
5. 中断後も数量を保持（ブラウザ内に保存）
6. リセット（確認つき）
7. 商品名の入力

### 技術スタック
React + Vite（安定版の最新を実装時に確認）。保存はブラウザの localStorage。

### 対象外
複数商品、履歴、Excel 出力、複数端末での共有、スマートフォン最適化。
